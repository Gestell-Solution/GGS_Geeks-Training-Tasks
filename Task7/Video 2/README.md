# Part 2 Summary: Traditional SDLC Models: Pros, Cons & When to Use Them

## SDLC Phases Documentation 

1. Definition & Planning :

1) Project Characteristics -> Objectives,General Scope &Project Overview 
2) Project Plan -> Timeline,Budget &Resources
3) CRS (Customer Requirement Specifications): almost written in business language. After has been done , it needs client's confirmation 
---
2. Requirement Analysis:

1) SRS
2) HRS
---
3. Design:

1) HLD 
2) SDD (Software Design Documentation)
3) LLD
4) UML 
---
4. Implementation:

1) Source Code Documentation (in Doxygen Style)
2) API Documentation 
---
5. Validation/Testing

1) Test Plan (what to test? who will? using which tools?)
2) Test Cases
3) Test/Bug Report 

---
6. Deployment & Maintenance ->

* For Deployment: 
1) Plan 
2) Release Note (explains which problems in the previous versions were solved or what the new features are)
3) User Manual

* For Maintenance:

1) Issue Log
2) Change Request

# SDLC Models 

# 1. WaterFall Model 

1] Requirements (Definition, Planning &Requirement Analysis)

2] Design (HLD, LLD-> Arch & Model) 

3] Implementation (Code)

4] Verification (Testing&Deployment)

5] Maintenance

* Its Problems:

1] Because it's sequential, it doesn't accept requirement change or edit. 

2] No early testing.

3] Customer is not involved in LifeCycle.

* Its Advantages:

1] Easy to use and understand.

2] Easy to manage.

3] Sequential (Once I'm done with one phase, I'm sure I won't come back)

* when to use:

1] For easy, short-term projects

2] With Non-pushy customers

---

# 2. V-Model: Upgraded version of WaterFall Model that strengthens *testing* 

1] Requirement

2] System Design 

3] Software Design 

4] Model Design

5] Coding

6] Unit Test

7] Integration

8] System Test

9] Acceptance Test

* Its Problems:

1] Customer is not involved in LifeCycle.

2] Doesn't support requirement change.


* Its Advantages:

1] Supports Early Testing.

2] Faster than WaterFall Model.

* when to use:

1] For simple projects

2] With Non-pushy customers

3] For Fast delivery
